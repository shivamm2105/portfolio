# Certificate Images Directory

Upload your certificate images (e.g. `.png`, `.jpg`, `.jpeg`, `.webp`) here!

### How to use:
1. Copy your certificate image into this folder (`public/certificates/`).
2. Update the filename in `src/data/certifications.js` for the corresponding certificate:
   ```javascript
   image: "/certificates/your-certificate-name.png"
   ```
3. The portfolio will automatically display your certificate image in cards and in the preview modal!
